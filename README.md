# ipobatumi-news

Новости ипотеки и банков Грузии и текущая ставка Нацбанка Грузии (НБГ) для сайта [ipobatumi.ru](https://ipobatumi.ru).

Сайт загружает файл `news.json` при каждом открытии страницы. Файл обновляется автоматически каждые два дня.

Формат `news.json`:
- `updated` — дата обновления (ГГГГ-ММ-ДД);
- `nbg_rate` — ставка рефинансирования НБГ, например `"8,25%"`;
- `items` — три новости, самая свежая первой. У каждой: `datetime`, `date`/`title`/`text` на `ru`, `ka`, `en`, `source` (`name`, `url`).
